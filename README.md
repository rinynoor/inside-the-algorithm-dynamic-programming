# 🧠 Inside the Algorithm — Week 06

## Dynamic Programming and Greedy Algorithms

Interactive learning media for **INF203 — Desain dan Analisis Algoritma**.

Students explore:

- Dynamic Programming

- Memoization
- Tabulation
- Greedy Algorithms
- Local choice
- Dynamic Programming vs. Greedy
- Choosing an algorithmic strategy based on problem characteristics

## 🎯 Learning Approach

The module uses an interactive step-by-step approach:

**Problem → Observe → Predict → Trace → Explain → Compare → Apply**

Students do not only see the final result. They observe **what the algorithm does at each step and why the decision is made**.

## 💡 Key Idea

### Dynamic Programming

**Solve → Store → Reuse**

Avoid solving the same subproblem repeatedly by storing and reusing previously computed results.

### Greedy Algorithm

**Evaluate → Choose → Commit**

Make a local choice at each step according to a Greedy rule.

The important question is not:

> “Which algorithm do I remember?”

but:

> **“What characteristics does this problem have?”**
